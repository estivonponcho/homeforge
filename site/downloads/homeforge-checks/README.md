# HomeForge practical checks

Download the complete-cost worksheet or the blank CAD measurement record. CAD files are unprinted educational examples, not validated fit recommendations. Plate 30 x 20 x 3 mm; slot height 6 mm; widths 10.0, 10.2 and 10.4 mm. The mesh checks establish closed geometry and expected volume only, not manufacturability or physical performance.

Define an acceptance criterion before printing. Record material, machine, slicer settings, instrument resolution, measured dimensions and uncertainty. Never use these examples for safety-critical qualification.
