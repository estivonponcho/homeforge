# Curated watch-and-build list

These public videos are useful starting points for HomeForge-style projects. They are references, not substitutes for testing: watch one, build something small, and write down what changed in the real installation.

## Smart home: build one reliable room

- [Zigbee + Home Assistant: Ultimate Beginner's Guide](https://www.youtube.com/watch?v=fHq2Bzrsnr8) — digiblur DIY. Use it to plan the coordinator and mesh before buying sensors.
- [5 Home Assistant Beginner Mistakes to Avoid](https://www.youtube.com/watch?v=i1083cCR2CI) — Everything Smart Home. Turn the failure modes into a preflight checklist.
- [Build a Smart Home Fingerprint Keypad](https://www.youtube.com/watch?v=Mt3QerTMITg) — Salim Benbouziyane. A strong ESPHome project once the basic system is stable.

**Build next:** a room-in-a-box starter setup with one contact sensor, one presence sensor, and one automation that still works when the internet is down.

## Homelab: start small and useful

- [What is a Homelab?](https://www.youtube.com/watch?v=5bsI3M44NWo) — Techquickie. A concise orientation before buying hardware.
- [Building a $20 Home Server You Can Actually Buy](https://www.youtube.com/watch?v=iZhaxXrKg7E) — TwoGuyzTech. Useful counterweight to expensive rack-build content.
- [I Wish I Knew This Before Building My Home Lab](https://www.youtube.com/watch?v=SzKo1wE0KeQ) — StuckAtPrototype. Turn the lessons into a maintenance and backup checklist.

**Build next:** put one low-power machine on a UPS and give it exactly three jobs: network filtering, remote access, and uptime monitoring.

## 3D printing: make the bench better

- [3D Prints You Will Actually Want to Make](https://www.youtube.com/watch?v=Umm1UpCA5AY) — InitMakes. Mine the ideas for functional, repeat-use parts.
- [50+ Useful 3D Prints for Beginners](https://www.youtube.com/watch?v=6-dZyJUvsBo) — Williams Workshop. Pick one organization problem instead of printing the whole list.
- [Turning 3D Print Waste into New Filament](https://www.youtube.com/watch?v=O6d1RKYapFI) — CNC Kitchen. Good context for the real tradeoffs behind waste claims.

**Build next:** print a five-piece homelab tidy-up kit—cable labels, drive tags, a mini-PC mount, a sensor enclosure, and a small-parts tray.

## Local AI: private before powerful

- [OpenAI's Monopoly Is Over! Local Intelligence Is Finally Here](https://www.youtube.com/watch?v=YbQCqyQrUl4) — Simon Høiberg. A useful overview; verify model claims before acting on them.
- [This Tiny Engine Runs Impossibly Big AI Models Locally](https://www.youtube.com/watch?v=3OqZHYNKc9A) — Better Stack. A technical prompt to think about memory and inference constraints.
- [I Built a Private AI Mini-Cluster with Framework Desktop](https://www.youtube.com/watch?v=N5xhOqlvRh4) — Jeff Geerling. Excellent inspiration, but start on hardware already owned.

**Build next:** run Ollama and Open WebUI on an existing computer, test one small model against five repeatable research prompts, and record latency, memory use, and answer quality.
