# The homelab server that uses about three watts

**Subject:** The homelab server that uses about three watts

Not every always-on job needs an old gaming PC humming in a closet.

My Quadra node handles network-wide DNS filtering and secure remote access over Tailscale while drawing roughly as much power as a phone charger. The interesting lesson isn't the specific box; it is matching the machine to the job.

Two rules make a tiny node dependable:

1. Use a mesh VPN instead of opening ports to the public internet.
2. Keep write-heavy data off fragile onboard storage.

Right-sized hardware means less electricity, less heat, and fewer moving parts to babysit.
